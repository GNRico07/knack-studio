FAQ

Questions we get all the time.

Do I need to provide hosting? +
Your site is delivered as clean, ready-to-deploy code. We can walk you through pushing it to GitHub and deploying on Netlify — which is what we use ourselves. Netlify's free tier handles hosting at no cost.
Can I update the site myself after it's built? +
Yes — everything is delivered via GitHub so updates are straightforward. If you'd prefer to hand it off, ongoing support is available as an add-on. Just reach out and we'll scope it together.
What if I don't have photos or a logo? +
No problem. We can create a logo concept and brand identity as an add-on, and we'll use high-quality placeholder imagery during the build until you're ready.
How does the revision process work? +
Every project includes revision rounds depending on scope. A revision round means you review the site, give us a consolidated list of changes, and we implement them. If you need more rounds, we'll agree on scope before any extra work begins.
Do you work with businesses outside Treasure Valley? +
Absolutely. Everything is done remotely — a discovery call over video or phone, files shared digitally. We work with businesses anywhere in the US.
What do I need to have ready before we start? +
Ideally: a general idea of what you want, any existing logo or brand assets, and a few examples of sites you like. That's it.
How do I pay? +
Full payment is collected upfront before work begins. This keeps things clean and simple — no chasing invoices, no awkward conversations. Accepted via card, bank transfer, Venmo, or Zelle.
